# data/个人信息数据/ — 个人信息类数据（仅分类说明，不入库）

本目录是**分类占位目录**，用于说明"哪些数据属于个人信息、敏感级别如何、运行时实际放在哪里"。
个人信息文件体积大、含身份证号/家庭情况等敏感字段，**不进入 Git 仓库**，只在本地与 U 盘私密包中流转。

## 本目录实际不含数据文件

为了保证运行时能正确校验政策证据链（`src/policy_core/local_evidence.py` 按原文件名 + SHA256
校验 `data/<原文件名>`），个人信息类源文件在运行时仍然必须放在 **`data/` 根目录**，不要移动到本目录。
本目录只作为分类说明与后续归档约定。

## 合规要求
