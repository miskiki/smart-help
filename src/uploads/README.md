# src/uploads/ — 用户上传文件目录（运行期，不入库）

本目录是政策 PDF 等上传文件的落盘位置，**运行期产物不入库**，仓库只保留本说明。

- 目录内容：用户/管理员通过页面上传的政策 PDF、导入用的 xlsx 等（带时间戳前缀）；
- 示例文件可参考原维护机的 12 个上传样例，由 U 盘私密包 `restore/src/uploads/` 恢复（可选，
  不提供也能正常启动，只是历史上传列表为空）；
- `src/static/exports/` 同理，为导出文件目录，也已排除。

## 注意

- 上传文件可能含业务敏感内容，**不要提交 Git**；
- 清理磁盘时可直接删除本目录内容，系统会自动重建目录。
